## Personal Projects

### 1. FIFA World Cup Data Analysis

## Objective
Analyze historical FIFA World Cup match data to identify trends in team performance, goal scoring, and tournament patterns.

## Dataset
Historical FIFA World Cup dataset including match results, teams, goals scored, and tournament information.

## Tools
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Insights
- Goal scoring trends have increased in recent tournaments.
- Certain national teams consistently perform well across multiple World Cups.
- Knockout stage matches tend to have lower average goals compared to group stage matches.
